# Windows 事件详情、自启与托盘

主界面的“查看详情与日志”显示当前恢复阶段、下一步，以及最近事件。诊断与设置页也有入口。每条事件按实际记录显示时间和节点；日志没记录节点时会明确说明。IP、DNS、HTTPS 分开显示；检查取消、超时和未执行保留不同含义。“技术字段”保留原事件代码，方便排查。

详情打开时每 5 秒读取一次本机有限日志片段，最多显示 500 条，支持搜索与跟随最新。关闭后停止读取。它不会执行测速、重连或换节点；完整轮转日志与排查资料仍由原有日志功能维护。读取失败保留已显示内容，拒绝不安全的日志文件。

在“诊断与设置 → 开机与状态显示”打开“开机自启”，会为当前 Windows 用户注册登录启动，默认关闭。登录时仅驻留托盘，不弹主窗口；是否自动连接继续由原有连接设置决定。关闭开关只删除本应用拥有的启动项；同名但属于其他程序的条目会报冲突并保留。系统启动应用策略仍可能禁止登录启动。

托盘地球图标随连接状态变色，悬停查看状态、节点和近期 ICMP 延迟；左键打开工作台，右键显示菜单。Windows 通知区域不支持和 macOS 菜单栏相同的常驻文字，故另有默认关闭的“小悬浮状态窗”，可拖动、点击正文打开主界面、点 × 关闭。它是实色小窗口，关闭后销毁。

延迟取自已有的外层节点 ICMP 测量，附测量年龄，不代表网站或整条隧道延迟。没有近期测量时明确显示暂无数据；物理断网、节点不一致、测量超过 180 秒或状态观察超过 3 秒时，不把旧数值作为当前延迟。以上显示不增加隧道或额外网络探针。


## 独立状态通道与延迟提示

状态读取使用独立的 SID/session 范围 `.Status` pipe，保留 API major、source SHA、build、boot、request ID、帧上限和 ACK 校验。它只接受 Dashboard；控制和私钥请求必须走原控制通道。后台每秒尝试发布一次不可变公有快照；状态端点不进入控制队列、不等待控制锁、不读取磁盘或调用远程 API。缺少快照或快照超过3秒时明确返回等待/更新延迟；读状态不会触发测速、换节点或重建隧道。控制 owner 存在但状态端点不可读时，不另启后台。首次启动仍需校验完整 runtime 与固定清单，启动门独立并限制重复拉起；明确退出后禁止自动重启。

主界面为本机状态读取保留固定高度的一行标题和一行说明，显示上次记录的年龄，与操作结果分别显示。读取忙、启动等待、发布延迟、校验/格式异常和持续读不到分别处理；取消不记故障，单次读取失败不能直接叫隧道断开。持续传输错误至少3次且跨10秒才提示无法读取本机状态，仍不替代真实隧道检测。未知错误正文不直接显示或泛化成后台离线。年龄计算不重复累加已在原生层计入的请求耗时。乱序响应、同一boot下倒退的sequence和超时送达的数据不刷新绿色状态；重复快照保留原观察时间。首次引导/恢复面板/托盘/小窗也不拿旧ready作当前成功，旧资料明确标识上次记录。

3秒限制是本机状态的发布年龄，不是每3秒远程检测一次，也不能单独证明此刻真实流量必通。正常主界面每1.5秒读一次状态。托盘优先复用这些观察；隐藏时或主界面长时间未更新时通过独立只读通道补读，不触发网络探针。托盘/小窗保留native观察年龄，超过3秒清除绿色和旧延迟。状态读失败时，前台暂停基于旧资料发起新的自动链式维护或跨候选续试，后台自己的恢复与正在处理的连接仍由原owner管理，读取状态不会取消它们。

这些是源码合同与隔离测试范围。源码和测试通过不代表已更新用户现用程序；云端只测试、不生成或安装候选时，真实新版本出口、长期稳定和升级验收仍为NOT_RUN。
