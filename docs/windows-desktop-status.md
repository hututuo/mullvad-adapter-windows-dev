# Windows 事件详情、自启与托盘

主界面的“查看详情与日志”显示当前恢复阶段、下一步，以及最近事件。诊断与设置页也有入口。每条事件按实际记录显示时间和节点；日志没记录节点时会明确说明。IP、DNS、HTTPS 分开显示；检查取消、超时和未执行保留不同含义。“技术字段”保留原事件代码，方便排查。

详情打开时每 5 秒读取一次本机有限日志片段，最多显示 500 条，支持搜索与跟随最新。关闭后停止读取。它不会执行测速、重连或换节点；完整轮转日志与排查资料仍由原有日志功能维护。读取失败保留已显示内容，拒绝不安全的日志文件。

在“诊断与设置 → 开机与状态显示”打开“开机自启”，会为当前 Windows 用户注册登录启动，默认关闭。登录时仅驻留托盘，不弹主窗口；是否自动连接继续由原有连接设置决定。关闭开关只删除本应用拥有的启动项；同名但属于其他程序的条目会报冲突并保留。系统启动应用策略仍可能禁止登录启动。

托盘地球图标随连接状态变色，悬停查看状态、节点和近期 ICMP 延迟；左键打开工作台，右键显示菜单。Windows 通知区域不支持和 macOS 菜单栏相同的常驻文字，故另有默认关闭的“小悬浮状态窗”，可拖动、点击正文打开主界面、点 × 关闭。它是实色小窗口，关闭后销毁。

延迟取自已有的外层节点 ICMP 测量，附测量年龄，不代表网站或整条隧道延迟。没有近期测量时明确显示暂无数据；物理断网、节点不一致、测量超过 180 秒或界面状态超过 15 秒未更新时，不把旧数值作为当前延迟。以上显示不增加隧道或额外网络探针。
