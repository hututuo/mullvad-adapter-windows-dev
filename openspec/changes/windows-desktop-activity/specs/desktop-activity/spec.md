# Requirements

- DA-1: Chinese event details show current recovery/next step, recorded relay, timestamp and probe outcomes. Include search, bounded history, technical codes and report export. Cancelled/unperformed checks are not dead nodes.
- DA-2: Absent/rotating/partial/untrusted logs are read safely and boundedly. Skip invalid rows with notice; read error retains displayed history. No account, keys, full paths or engine output cross endpoint.
- DA-3: Startup and status widget default OFF. Never register automatically or modify foreign startup value.
- DA-4: Tray/widget display verified status and ICMP age. Stale snapshots cannot imply current health. Drag/open/close never changes tunnel.
