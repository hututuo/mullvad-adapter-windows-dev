# Reliability and boundary corrections

Close independently reproduced controller authentication, process ownership,
local-failure classification, cancellation, diagnostic-export and build-origin
defects on the Mac and Windows implementations. Add correlated status timings
to distinguish slow local service reads from negative tunnel evidence.

Preserve original-path and same-city recovery, unique peer ownership, required
protection and the front's REJECT fallback. Source regression checks are distinct
from Windows native compilation, installation, egress and sustained recovery.
This change does not implement new transport or protection features, deploy an
update, or establish one historical cause for every status timeout.
