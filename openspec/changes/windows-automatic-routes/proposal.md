# Windows automatic catalogue and optional tunnel carrier

Cached metadata without automatic refresh and a disconnected restart require
manual recovery. Add a bounded background catalogue lane, a one-shot startup
connection intent and an explicitly configured independent SS fallback carrier.
Keep the city boundary, original-path priority, physical-offline pause, peer
lease, current-operation fences, fresh readiness and rejecting front.

This change does not add a system TUN, DIRECT fallback, TCP/QUIC transport,
account/device mutations, concurrent spare tunnels or a Mac runtime change.
