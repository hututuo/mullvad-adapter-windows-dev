# Requirements

## ID-1 本机身份列表

WHEN 已保存多份身份，THEN 授权账号页显示账号尾号、设备名、公钥、当前选择；未知设备名必须标注。普通状态/日志/列表不输出完整账号、私钥或令牌。历史官方设备名不当作当前登记证明。

## ID-2 串行切换与持久化

WHEN 用户明确切换，THEN 使用统一操作准入，取消旧恢复意图，在生命周期锁内停止全部旧 worker 后才提交新身份。旧检测结果按 generation 失效。账号、密钥和隧道地址以一个私有文件的原子替换提交；不得覆盖旧模板。清理未完成时不得选中新身份。响应丢失只读回，不重复提交。

WHEN 身份提交完成但网络验证失败，THEN 如实显示所选身份与联网失败，允许重试或手动切回，不能报连接成功。

## ID-3 身份与账号管理的区别

WHEN 用户退出账号管理，THEN 保存的隧道身份保留，但重启后不能恢复已退出的管理登录。账号页明确设备列表查询与当前隧道身份可能不属于同一账号。

## NET-1 地址族准入

WHEN 用户选择 IPv6 但本机观察中没有 IPv6，THEN 不启动切换，不停止原通道，返回明确的本机 IPv6 不可用原因。WHEN 解析 IPv6 外层物理接口，THEN 接口必须有有效非链路本地 IPv6 源地址；暂定/重复/已脱离的地址不计入。

## OBS-1 不确定观察与延迟

WHEN IP/HTTPS 未通过且存在本机观察不确定性，THEN 不增加节点失败、SS 失败历史或触发换节点。WHEN 显示菜单栏延迟，THEN 当前数据通道必须通过 DNS/HTTPS 验证、结果未过期且不早于本次切换；恢复中/失败中的外层 ping 只能标为旧诊断。日志记录 ping 来源以及 IP/DNS/HTTPS 的独立结果。
