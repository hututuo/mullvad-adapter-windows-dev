# Account management survives a missing tunnel identity

Saved local identities and a verified account login are different objects. A revoked device must not strand the user behind a cached list or a switch-only UI. Provide input-based login and per-saved-account management, explicit list freshness, safe new-device saving/activation, and a preemptive Stop action. Existing WireGuard keys, same-city behavior and uncertain-mutation guards remain protected. This change implements the Mac product path; Windows is not implicitly given Mac saved-profile functionality.
