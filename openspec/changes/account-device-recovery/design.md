# Design

`AccountLifecycle` separates management snapshots and current-identity observations from the tunnel. Management commands retain the existing nonblocking account lock; local reads can return the last coherent snapshot while a writer works. Publish under the account lock, never merge two accounts into one snapshot. Current identity owner is the selected profile, or a unique legacy key match. Unknown/missing-on-another-account does not revoke a tunnel. Fresh absence of a previously registered own key suppresses futile recovery until registration is confirmed again or the user chooses another identity.

A bounded, credential-free TLS API-address discovery chooses a control route before credentials or device writes. Official address, hostname/SNI/certificate rules follow the pinned upstream; the selected route is fixed for the account transaction. No device mutation is replayed after unknown network outcomes. Normal monitoring is 300 seconds, failure/data_fail recheck no faster than60 seconds; page entry explicitly refreshes, subsequent 5-second reads are local only. No monitor creates/revokes devices.

New registered keys require exact durable registration receipts, account binding, matching public/private key and official allocated addresses. Save to owner-private profiles without activation; activate through the existing exclusive stop/commit/reconnect flow. Keys stay in local state/Keychain. Saved account management never changes the data identity.

`ConnectionControl` persists manual stop intent, invalidates old operations, attempts cleanup of every owned worker and front even after an individual failure, and distinguishes uncertain cleanup or persistence from confirmed stop. Stop does not queue behind normal action admission. Local management API remains available; background remote checks pause. Explicit connection intent can resume only if not overtaken by a newer Stop. UI termination waits for the matching stop receipt and a fresh stopped status. Source component hashes bind the new Ruby modules in future assembly/upgrade checks.
