# Design

The owner publishes a bounded immutable public Dashboard once per second. Encode before a nonwaiting pointer swap; readers take only a short nonwaiting cache reference and write outside the cache lock. Separate SID/session-scoped .Status pipe handles Dashboard only, with the existing major/source/build/boot handshake, bounded frames/deadline and ACK. It never enters the control queue, runs remote I/O or accesses keys. Missing/over-3-second publications return typed read errors, not renewed old ready. Control stays serialized; status has a separate local gate. A shared short startup gate plus read-only control-instance presence check avoids spawning a second backend when its status channel is temporarily unavailable. Shutdown fencing applies to both channels.

Native status observations include age/capture/native elapsed time; request/delivery delay cannot refresh old data, and time already counted by native is not counted twice in the renderer. Renderer state-read health is independent of operation feedback, preserves last known data and orders completions, and distinguishes pending/busy/stale/format-or-auth failures from sustained transport failures. Age is visible; expired evidence loses green connected/Ping presentation. Tray/widget reuse the original observation time. Logs accept only closed categories and numeric timings, never arbitrary failure payloads or credentials. Tests use synthetic snapshots and isolated IPC, not tunnels or installed apps.
