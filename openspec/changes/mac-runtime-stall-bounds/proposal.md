# Bound local runtime observations

Short HTTP/curl timeouts did not bound subprocess capture or aggregate probe-thread waits. A slow listener ownership command could extend controller startup; one slow diagnostic destination could also trigger a front restart even while another service remained reachable.

Bound short-lived local probe subprocesses and aggregate canaries, distinguish local execution failure from negative tunnel evidence, and require an independent service check before front repair. Preserve the existing installed runtime until separately authorized replacement. This change does not establish the historical cause of every local TCP timeout or claim a deployed stability fix.
